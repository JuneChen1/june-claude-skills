# HoyoLab to X Post

當使用者提供 HoyoLab 文章連結，自動抓取內容並生成可直接貼到 X 的發文草稿。

## 適用情境

- 使用者說「幫我生成 X 發文」、「產生推文」、「把這篇文章轉成 X 格式」
- 使用者貼出 hoyolab.com/article/ 開頭的連結

## 不適用情境

- 非 HoyoLab 文章連結
- 使用者只是想聊文章內容

## 工作流程

1. 確認使用者提供的 HoyoLab 文章連結
2. 用 Chrome MCP 開啟頁面，等待內容載入，關閉彈出視窗
3. 讀取頁面快照，擷取：
   - 文章標題
   - 文章標籤（頁面底部的 tag 列表）
   - 摹本碼 / Replica ID：只從頁面文字快照（a11y tree / innerText）中找純數字 ID，搭配附近的伺服器或地點名稱；**不嘗試讀取圖片或截圖**
   - 伺服器：只在文章中明確讀到「亞服」或「台服」時才加入 🌿 那一行；讀到「亞服」→「🌿 Asia server」，讀到「台服」→「🌿 TW/HK/MO server」；兩者都沒讀到 → 省略整行 🌿
4. 若使用者提供遊戲截圖（含「洞天摹數」欄位），從截圖讀取：
   - 地點格式為「A-B」（如「妙香林-明智台」），只取 `-` 後面部分（B）作為標籤
   - 洞天摹數數字即為摹本碼
5. 若找到摹本碼 → 照格式輸出
6. 若找不到摹本碼 → 先輸出省略摹本碼區塊的草稿，再問使用者：「我在文章文字中找不到摹本碼，你有摹本碼嗎？如有請提供碼和地點名稱（如明智台），我幫你加上去」；**不繼續嘗試從圖片或 JavaScript 中提取**
7. 若使用者補上摹本碼 → 輸出加入摹本碼區塊的完整草稿（重新計算字元數）
8. 標籤判斷：
   - 讀取 `x/tags.json`
   - `global_hashtags`：每篇都加，固定附在草稿結尾
   - `article_tag_to_hashtags`：比對文章標籤與 JSON 的 key，若有符合 → 將對應 value 的 hashtag 陣列附加在 global_hashtags 之前
   - 可同時符合多個 key（多組 hashtag 依序附加）
   - hashtag 區塊格式：[文章符合的 hashtags] [global_hashtags]

## 輸出格式

含摹本碼時：

```
[標題]

🌿 Asia server（讀到「台服」則改成「🌿 TW/HK/MO server」；都沒讀到則省略此行）
📌 洞天摹數 (Replica ID)：[摹本碼]
👉 區域：[地點]

✨ 詳細介紹 (HoYoLab) 👇
[連結]（省略 https://www. ，格式為 hoyolab.com/article/[ID]）

[文章符合的 hashtags（若有）] [global_hashtags]
```

**無摹本碼時（先輸出此版本，再詢問）**：

```
[標題]

✨ 詳細介紹 (HoYoLab) 👇
[連結]（省略 https://www. ，格式為 hoyolab.com/article/[ID]）

[文章符合的 hashtags（若有）] [global_hashtags]
```

## 字數檢查

輸出草稿後，計算總字元數並標示（只輸出一行結果，不列表格、不逐項說明）：
- URL 固定算 23 字元（X 的 t.co 短網址機制）
- 其餘字元（含中文、標點、換行）各算 1 字元
- 上限 280 字元
- 若超過：在草稿下方標示 `⚠️ 超過 280 字元（目前 X 字），請刪減後再發`
- 若未超過：標示 `✅ X 字元 / 280`

## 安全限制

- 不登入 HoyoLab
- 不送出任何表單
- 不自動發文到 X，只產生草稿供使用者複製
