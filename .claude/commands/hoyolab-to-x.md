# HoyoLab to X Post

當使用者提供 HoyoLab 文章連結，自動抓取內容並生成可直接貼到 X 的發文草稿。

## 適用情境

- 使用者說「幫我生成 X 發文」、「產生推文」、「把這篇文章轉成 X 格式」
- 使用者貼出 hoyolab.com/article/ 開頭的連結

## 不適用情境

- 非 HoyoLab 文章連結
- 使用者只是想聊文章內容

## 工作流程

1. 確認使用者提供的 HoyoLab 文章連結
2. 用 Chrome MCP 開啟頁面，等待內容載入，關閉彈出視窗
3. 讀取頁面快照，擷取：
   - 文章標題
   - 摹本碼 / Replica ID：在文章中找純數字 ID（通常 13 位），搭配附近的伺服器或地點名稱
4. 若使用者提供遊戲截圖（含「洞天摹數」欄位），從截圖讀取：
   - 地點格式為「A-B」（如「妙香林-明智台」），只取 `-` 後面部分（B）作為標籤
   - 洞天摹數數字即為摹本碼
5. 若找到摹本碼 → 照格式輸出
6. 若找不到摹本碼 → 輸出時省略該區塊，並在草稿下方說明「未找到摹本碼，請確認是否需要補上」

## 輸出格式

```
[標題]

📌洞天摹數 (Replica ID)：
[伺服器]：[摹本碼]

HoYoLab：
[完整連結]

#塵歌壺 #sereniteapot
```

若有多組摹本碼，每組一行：

```
[標題]

📌洞天摹數 (Replica ID)：
[伺服器A]：[摹本碼]
[伺服器B]：[摹本碼]

HoYoLab：
[完整連結]

#塵歌壺 #sereniteapot
```

## 安全限制

- 不登入 HoyoLab
- 不送出任何表單
- 不自動發文到 X，只產生草稿供使用者複製
