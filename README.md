# Claude Code Skills

## Skills 清單

| Command | 名稱 | 說明 |
|---------|------|------|
| `/add-inbody` | 新增 InBody 數據 | 新增 InBody 量測數據：自動讀取圖片、解析數據、更新 JSON 與 Excel。 |
| `/agent-launcher` | Agent 分工設計 | 引導使用者設計自己的 agent 分工，再根據任務啟動或切換專屬 agent。適合建立研究、寫作、資料分析、程式開發、規劃與審查等角色。 |
| `/chrome-mcp` | 瀏覽器自動化 | 使用 Chrome MCP 或瀏覽器自動化工具協助開網頁、點擊、填表單、截圖與檢查頁面狀態。適合操作使用者有權限使用的網站，不適合大量爬蟲。 |
| `/csv-financial-report` | CSV 財務報表 | 先確認 CSV 欄位、分類規則與匿名化需求，再用使用者提供的 CSV 或表格資料產生分類統計報表。 |
| `/custom-work-partner` | 溫柔陪跑者 | 溫柔陪跑者，幫使用者找出解決方法。當使用者遇到困難或卡關時，直接給出選項讓使用者選擇方向，優先考量安全、效率與長期目標。 |
| `/nutrition-log-review` | 飲食紀錄分析 | 先訪談使用者的飲食目標、限制與偏好，再協助分析飲食紀錄並提出可執行建議。適合日常飲食回顧，不取代醫療診斷。 |
| `/retrospective` | 覆盤 | 先確認覆盤對象、目標與角度，再對一次工作、學習、對話或 skill 使用過程做覆盤，產出下一版改進建議。 |
| `/route-planner` | 路線規劃 | 根據日期、目的地與交通偏好，協助規劃出發時間、路線、轉乘與緩衝時間。第一次使用時先建立交通偏好。 |
| `/scheduler` | 排程助理 | 使用已授權的行事曆資料協助找空檔、安排會議與檢查衝突。第一次使用時先建立排程偏好，適合搭配 Google Calendar API 或行事曆 MCP 工具。 |
| `/skill-writing-guide` | Skill 寫作教練 | 先訪談使用者要寫的 skill 類型、輸入輸出、工具風險與使用情境，再產生或審查可直接使用的 SKILL.md。 |
| `/work-partner-persona` | 工作合夥人人設 | 引導使用者逐步建立自己的工作合夥人 Persona Skill。先訪談使用者的需求、關係、語氣與邊界，再產生可直接使用的 SKILL.md。 |
